# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Chrome and Chromium browser users seeking modern, high-speed ad and tracker protection, zero-delay video playback, lightweight RAM footprint, and cloud rule sync via TXA Studio.

## Product Purpose
ShieldBlock Pro is a lightweight, efficient, and privacy-focused Manifest V3 content blocker. It blocks intrusive ads, trackers, coin-miners, and anti-adblock traps, while providing one-click element zapping/picking and multi-device cloud synchronization.

## Positioning
Combines Chrome native Declarative Net Request (DNR) execution with smart client-side anti-trap scripts, YouTube ad skip engines, and TXA Studio Cloud Sync on Supabase.

## Operating Context
- Browser Extension Action Popup: Domain toggle, stats counter, element picker/zapper, YouTube accelerator, smart guard, TXA cloud status, and Telegram community channel.
- Options & Dashboard Page (`dashboard.html`): High-end control center for protection profiles, filter lists, user DNR rules, cloud synchronization, and diagnostics.

## Capabilities and Constraints
- Manifest V3 Chromium architecture (Service Worker, declarativeNetRequest, offscreen compiler).
- Offline-first local evaluation with optional TXA Cloud Sync.
- Standardized extension popup dimensions and modern dashboard layout.

## Brand Commitments
- Name: ShieldBlock Pro
- Aesthetic: Cyberpunk neon cyan (`#38bdf8`), purple (`#a855f7`), emerald (`#22c55e`), and deep slate dark mode (`#0b0f19`).
- Typography: Inter, Outfit, system sans-serif.

## Product Principles
1. Zero lag, zero bloat: Native browser declarative execution.
2. Uncompromising privacy: No browsing logs, no telemetry without explicit user feedback.
3. Unified TXA ecosystem: Single TXA Studio ID across games and extensions.
4. Out-of-distribution visual craft: Premium, alive, polished design across popup and dashboard.
